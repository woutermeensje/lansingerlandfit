# Context voor Codex

Lees vóór het werken aan dit project de volgende context en volg de relevante instructies:

1. `~/.claude/CLAUDE.md` voor de algemene voorkeuren en werkwijze van Wouter.
2. `CLAUDE.md` in de hoofdmap van dit project, indien aanwezig. Controleer ook `claude.md` als het bestand zo heet.
3. Aanvullende `CLAUDE.md`- of `claude.md`-bestanden in de submappen waarin je werkt, indien aanwezig.

Lees ook de bestanden waarnaar deze context verwijst wanneer die relevant zijn voor de taak. Houd de context in de oorspronkelijke bestanden; kopieer die niet naar dit bestand.
